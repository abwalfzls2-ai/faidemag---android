# فایدمگ — پروژه اندروید

این پروژه یک اپ آفلاین اندرویدی است که رابط فارسی فایدمگ را داخل WebView نمایش می‌دهد.
- نام برنامه: فایدمگ
- شناسه: ir.faidemag.study
- داده‌ها در فضای داخلی WebView ذخیره می‌شوند.
- آیکون برنامه به‌صورت Vector Drawable تعریف شده است.

## ساخت APK
این پوشه یک پروژه منبع Android Gradle است، نه APK آماده. برای ساخت APK باید آن را در محیط سازگار با Android SDK و Gradle build کنید. در گوشی می‌توانید از ابزار ساخت APK سازگار با پروژه‌های Android استفاده کنید یا پروژه را به مخزن GitHub منتقل کرده و با workflow مناسب build بگیرید.
